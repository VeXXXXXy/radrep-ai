# RadRep.ai

**AI-assisted radiology dictation and report drafting for clinical workflows.**

Website: https://radrep.ai/

RadRep.ai helps radiologists turn dictated findings into structured report drafts. The product is designed to work alongside existing PACS and RIS workflows through browser and desktop experiences.

## What the product offers

Based on the publicly available product information:

- Medical-context voice dictation.
- Structured radiology report drafting.
- Study-specific template selection.
- Formatting and terminology support.
- Browser side-panel workflow for web-based PACS/RIS.
- Windows desktop overlay for compatible local imaging and reporting applications.
- Human review and approval before a report is finalized.

## Intended users

- Radiologists
- Reporting clinicians
- Diagnostic imaging centres
- Hospitals and teleradiology providers

## Medical-use statement

RadRep.ai supports documentation workflows. AI-generated text must be checked by an appropriately qualified clinician before use or signature. The treating or reporting clinician remains responsible for the final report.
