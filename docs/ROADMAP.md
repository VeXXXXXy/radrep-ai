Public roadmap
This roadmap describes areas for continued product development. It does not promise delivery dates.
Near-term focus
- Improve onboarding and setup guidance.
- Expand public documentation for supported workflows.
- Collect structured feedback from radiology professionals.
- Improve clarity around supported applications and configurations.
- Document known limitations and troubleshooting steps.
Longer-term areas to explore
- More configurable reporting templates.
- Broader workflow compatibility.
- Clearer administrative controls for clinical teams.
- More detailed product and release documentation.
Suggest an improvement
Open a GitHub Issue with a clear title, use case, expected outcome, and non-sensitive example. Never attach real patient information or medical images.
