Product capabilities
The following capabilities are described on RadRep.ai's public website and product listing. Availability may vary by product version and account.
Dictation
Voice input designed for radiology terminology and reporting workflows.
Structured report drafting
Dictated content can be organized into report sections such as findings and impression.
Template support
The product describes template selection for different study types and modalities.
Browser workflow
The RadRep Side Panel Chrome extension is described as a way to dictate and draft reports alongside web-based PACS or RIS applications.
Desktop workflow
The website describes a Windows desktop application with an always-on-top interface for use alongside local imaging or reporting software.
Clinician review
Generated text should be reviewed and corrected by the responsible clinician before it is transferred, finalized, or signed.
