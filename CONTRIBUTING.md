# Contributing

Thank you for helping improve the public documentation around RadRep.ai.

## What you can contribute

- Clearer setup and user guidance
- Documentation corrections
- Non-sensitive workflow examples
- Accessibility and usability suggestions
- Bug reports about this repository's documentation

## Before opening an issue

1. Search existing issues.
2. Describe the problem and the expected result.
3. Include product version or browser/OS details when relevant.
4. Remove all patient information and secrets.

## Pull requests

- Keep changes focused.
- Explain why the change is useful.
- Do not submit proprietary production code unless you have explicit authorization to release it.
- Do not add patient data, credentials, or private customer information.

By contributing, you confirm that you have the right to submit the material under the repository's license.
